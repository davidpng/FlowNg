What does this check?

A shared FlowNG file is the FlowNG program plus one block of data. This page compares the program part of your file, letter for letter in a normalised form, with every released version of FlowNG listed in manifest.json (only versions released on the main branch). It also checks that the data block is plain data and nothing else. Who made the file does not matter: any file built from a released version passes.

A green result means the file's program code is a released FlowNG build and its data block contains data only. It does not mean the analysis itself is correct, or that a file contains no patient information.

A red result means do not open the file. Ask the sender for a fresh copy from the source you trust, or download FlowNG from the official site.

Only trust this page at its official address, https://davidpng.github.io/FlowNg/check/. This page cannot protect you from a fake copy of itself.

FlowNG is research software, not for clinical diagnostic use.
